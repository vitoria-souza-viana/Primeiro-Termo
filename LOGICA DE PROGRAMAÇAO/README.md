# 🐍 Curso: Lógica de Programação com Python & Clean Code
**Foco:** Algoritmos, Escrita Limpa e Versionamento Profissional com GitHub

---

## 📑 Módulo 1: Lógica de Programação com Python
*   **Introdução à Sintaxe Python:**
    *   Variáveis e Tipos de Dados (int, float, str, bool).
    *   Entrada e Saída de dados (`input` e `print`).
*   **Estruturas Condicionais:**
    *   `if`, `elif`, `else`.
    *   Operadores lógicos (`and`, `or`, `not`) e relacionais.
*   **Estruturas de Repetição:**
    *   `while` e `for` (uso do `range`).
*   **Coleções de Dados:**
    *   Listas, Tuplas e Dicionários.

---

## 🧹 Módulo 2: Clean Code (Código Limpo)
*   **Nomes Significativos:**
    *   Como nomear variáveis, funções e classes (evitar nomes como `x`, `temp`, `data`).
*   **Funções Pequenas e Especializadas:**
    *   O princípio da responsabilidade única (fazer apenas uma coisa).
*   **Comentários:**
    *   Quando são necessários e quando o código deve se autoexplicar.
*   **Formatação e PEP 8:**
    *   O guia de estilo oficial da linguagem Python.

---

## 🛠️ Módulo 3: Desenvolvimento Modular e Funções
*   **Definição de Funções (`def`):**
    *   Parâmetros, argumentos e retorno de valores.
*   **Tratamento de Erros:**
    *   Blocos `try`, `except` e `finally`.
*   **Importação de Módulos:**
    *   Uso de bibliotecas padrão do Python (math, random, datetime).

---

## 🐙 Módulo 4: Git e GitHub (Versionamento)
*   **Conceitos de Git:**
    *   O que é controle de versão?
    *   Ciclo de vida do arquivo: *Untracked, Staged, Committed*.
*   **Comandos Essenciais:**
    *   `git init`, `git add .`, `git commit -m "mensagem"`.
    *   `git status` e `git log`.
*   **Trabalhando com GitHub:**
    *   Criando repositórios remotos.
    *   `git push` e `git pull`.
    *   O papel do arquivo `README.md`.

---

## 🚀 Projeto Final: O "Clean Scraper" ou "Task Manager"
1.  **Objetivo:** Criar um gerenciador de tarefas por linha de comando.
2.  **Requisitos:**
    *   Código totalmente em Python.
    *   Aplicação de funções e estruturas de repetição.
    *   Nomes de variáveis seguindo as regras de **Clean Code**.
    *   Repositório público no **GitHub** com commits organizados.
