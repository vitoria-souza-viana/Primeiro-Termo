# 🖥️ Curso: Sistemas Operacionais
**Foco:** Gestão de Recursos, Modelos de Software e Prática com Linux

---

## 📑 Módulo 1: Gerenciamento de Hardware (O Papel do Kernel)
*   **O que é o Kernel?** A ponte entre o hardware e o software de usuário.
*   **Gerenciamento de Processos:** 
    *   Como o SO divide o tempo da CPU (Escalonamento).
    *   Estados de um processo (Pronto, Executando, Bloqueado).
*   **Gerenciamento de Memória:** 
    *   Memória RAM vs. Memória Virtual (Swap).
    *   Paginação e Segmentação.
*   **Gerenciamento de E/S (Entrada e Saída):** 
    *   O papel dos Drivers.
    *   Interrupções de hardware vs. Polling.

---

## 📂 Módulo 2: Código Aberto (Open Source) vs. Código Fechado (Proprietário)
*   **Sistemas de Código Fechado:**
    *   **Exemplos:** Windows, macOS, iOS.
    *   **Características:** Licenças pagas, código restrito, suporte corporativo centralizado.
*   **Sistemas de Código Aberto:**
    *   **Exemplos:** Linux (Kernel), FreeBSD, Android (AOSP).
    *   **Filosofia:** As 4 liberdades (Executar, Estudar, Redistribuir e Modificar).
    *   **Licenciamento:** GPL, MIT e Apache.

---

## 🐧 Módulo 3: O Ecossistema Linux
*   **Distribuições (Distros):** 
    *   Para iniciantes (Ubuntu, Mint).
    *   Para servidores (Debian, CentOS/Rocky Linux).
    *   Para usuários avançados (Arch Linux, Gentoo).
*   **A Estrutura de Diretórios:** Entendendo o `/root`, `/home`, `/etc`, `/bin` e `/var`.
*   **Interface de Linha de Comando (CLI):** O poder do Terminal.

---

## 🛠️ Módulo 4: Prática - Instalação do Linux
*   **Preparação do Ambiente:**
    *   Criação de Mídia Bootável (Ferramentas: Rufus ou Ventoy).
    *   Configuração de BIOS/UEFI (Secure Boot e Ordem de Boot).
*   **Particionamento de Disco:**
    *   Diferença entre Partição Primária e Estendida.
    *   Sistemas de Arquivos (EXT4 vs. NTFS).
    *   Conceito de Dual Boot (Linux ao lado do Windows).
*   **Pós-Instalação:** 
    *   Atualização de repositórios (`sudo apt update`).
    *   Instalação de pacotes básicos.

---

## 🚀 Desafio Prático
1.  **Laboratório:** Instalar uma distribuição Linux (ex: Ubuntu Desktop) em uma Máquina Virtual (VirtualBox ou VMware).
2.  **Configuração:** Criar um usuário, configurar a rede e identificar o uso de memória RAM via terminal com o comando `free -m`.
