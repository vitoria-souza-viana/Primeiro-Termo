# 📋 Curso: Engenharia de Requisitos
**Foco:** Levantamento, Classificação, Modelagem e Relatórios

---

## 📑 Módulo 1: Fundamentos do Levantamento de Requisitos
*   **O que são Requisitos?** Definição de necessidades do cliente vs. funcionalidades do sistema.
*   **Técnicas de Elicitação:**
    *   Entrevistas (Estruturadas e Não-Estruturadas).
    *   Questionários e Brainstorming.
    *   Observação de campo (Etnografia).
    *   Prototipagem rápida.

---

## 🔍 Módulo 2: Requisitos Funcionais (RF) vs. Não Funcionais (RNF)
*   **Requisitos Funcionais (RF):**
    *   O que o sistema deve **fazer**.
    *   Exemplo: "O sistema deve permitir o cadastro de novos usuários."
*   **Requisitos Não Funcionais (RNF):**
    *   Como o sistema deve se **comportar** (Qualidade).
    *   **Categorias:** Desempenho, Segurança, Usabilidade, Confiabilidade e Disponibilidade.
    *   Exemplo: "O sistema deve responder a qualquer consulta em menos de 2 segundos."

---

## 📊 Módulo 3: Modelagem com Diagramas (UML)
*   **Diagrama de Caso de Uso (Use Case):**
    *   Atores, Casos de Uso e Relacionamentos (Include, Extend).
    *   Foco no valor entregue ao usuário.
*   **Diagrama de Fluxo de Dados (DFD) ou Atividade:**
    *   Entendendo o passo a passo do processo de negócio.
*   **Protótipos de Baixa Fidelidade:**
    *   Wireframes para validação visual de requisitos.

---

## 📄 Módulo 4: Documentação e Relatórios
*   **Documento de Especificação de Requisitos de Software (SRS):**
    *   Estrutura padrão (IEEE 830).
*   **Matriz de Rastreabilidade:**
    *   Garantir que cada requisito esteja ligado a uma necessidade de negócio e a um teste futuro.
*   **Relatórios de Impacto:**
    *   Análise de mudanças e como elas afetam o cronograma e custo.

---

## 🛠️ Atividade Prática: Do Problema ao Documento
1.  **Cenário:** "Sistema de Agendamento para uma Clínica Médica".
2.  **Exercício 1:** Listar 5 Requisitos Funcionais e 3 Não Funcionais.
3.  **Exercício 2:** Desenhar o Diagrama de Caso de Uso para o "Médico" e o "Paciente".
4.  **Exercício 3:** Redigir a descrição detalhada de um Caso de Uso principal.
